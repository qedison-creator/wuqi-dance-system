# paper 皮肤思源宋体 · 上传说明

paper 皮肤的宋体大字在安卓端依赖在线字体（iOS 系统自带宋体，不依赖此文件）。字体已子集化压缩，需**一次性**上传到服务器，之后小程序会在进入 paper 皮肤时自动加载（失败静默回退系统宋体栈，不影响任何功能）。

## 一、上传文件

| 本地文件（docs/fonts/） | 上传到服务器 | 大小 | 字重 |
|---|---|---|---|
| NotoSerifSC-Regular-subset.woff2 | /uploads/fonts/NotoSerifSC-Regular-subset.woff2 | 1.35 MB | 400 常规 |
| NotoSerifSC-Bold-subset.woff2 | /uploads/fonts/NotoSerifSC-Bold-subset.woff2 | 1.39 MB | 700 粗体 |

目标 URL（最终必须能这样访问到）：

- `https://api.yuekeme.cn/uploads/fonts/NotoSerifSC-Regular-subset.woff2`
- `https://api.yuekeme.cn/uploads/fonts/NotoSerifSC-Bold-subset.woff2`

即：上传到后端服务器上 nginx 静态目录的 `uploads/fonts/` 下（与现有 `/uploads/` 图片目录同级）。

## 二、nginx 检查（两项）

**1. woff2 的 MIME 类型**（nginx 一般已内置，若下载后小程序端识别失败再加）：

```nginx
# http{} 块内，若已有 types 中无 woff2 则补一行
types {
    font/woff2 woff2;
}
```

**2. 字体目录的 CORS 头**（iOS 端 loadFontFace 强制要求，缺失会导致 iOS 加载失败）：

```nginx
# server{} 或对应 location 内
location /uploads/fonts/ {
    add_header Access-Control-Allow-Origin *;
}
```

改完 `nginx -s reload`。

## 三、小程序后台域名检查

微信小程序管理后台 → 开发管理 → 开发设置 → 服务器域名：确认 `api.yuekeme.cn` 已在 **downloadFile 合法域名** 列表中（loadFontFace 网络字体走该白名单；若已配过则忽略此步）。

## 四、上传后验证

浏览器直接打开上面两个 URL，应触发下载/显示乱码二进制而非 404。或命令行：

```bash
curl -sI https://api.yuekeme.cn/uploads/fonts/NotoSerifSC-Regular-subset.woff2
# 期望：HTTP 200，Content-Type 为 font/woff2 或 application/octet-stream，且有 Access-Control-Allow-Origin
```

开发者工具中切换到「纸上舞台」皮肤，控制台不报 loadFontFace 错误、宋体生效即为成功。**文件未上传时无任何影响**：皮肤自动回退系统宋体栈（iOS 完美，安卓部分机型回退黑体）。

## 五、字体规格备忘

- 源字体：Noto Serif SC（思源宋体）官方可变字体，实例化出 400/700 两个静态字重
- 字符集 7602 字：ASCII 全量 + GB2312 全表（6763 汉字 + 中文标点全角符号）+ 工程源码出现过的全部非 ASCII 字符 + 常用补充（〇、箭头等），动态内容（会员名、公告等）覆盖率达 99.9%
- 若未来遇到极生僻字显示为回退字体，把该字补进子集字符集重新生成即可（脚本已留存：`%TEMP%/fontwork/subset.js`）
