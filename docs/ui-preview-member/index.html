纸上舞台PAPER STAGE · UI / UE PROPOSAL V1.0

把会员端从「App 感」做成「刊物感」：纸色底、墨色字、发丝分隔线、宋体大标题、编号系统，全局只留一抹朱砂红用在「动作」上。去掉渐变按钮、玻璃拟态、糖果色大圆角卡片这类被用滥的手法——像一本安静、讲究的舞蹈志，而不是一个通用模板。

壹 / 01设计理念Philosophy
其一

纸上舞台

整体材质是「纸」：暖纸色底 + 颗粒肌理，卡片靠发丝线区分而不是阴影堆砌。圆角收小（卡片 8px、按钮 3px），直角偏多的版面天然显得贵。

PAPER · GRAIN · HAIRLINE
其二

一抹朱砂

全局只有朱砂红一个强调色，像印章一样「盖」在关键动作上：预约按钮、当前日期、新增角标。其余信息全部用墨色深浅表达，画面自然安静。

新
其三

编排即节奏

用杂志排版的节奏感呼应舞蹈：中英文双语小标、壹贰叁编号、大号宋体时间数字、竖排点题字。信息密度不变，但阅读有了主次和呼吸。

版式规则

元素规则
区块标题编号（壹/贰/叁 或 01/02）+ 宋体标题 + 英文小字注脚，下压一条双细线——印刷刊头的做法
分隔一律用 1px 发丝线；重要分界用「双细线」；不用大色块、不用阴影堆砌
列表公告、记录类列表加「01 02 03」编号， magazine 目录感
圆角卡片 8px，按钮/输入框 3px，标签 2px，头像方形 4px（圆形头像仅保留教练/本人照片一处）
阴影默认无阴影；仅弹层允许「2px 实体错位影」（模拟纸张叠放），不用扩散模糊影
竖排点题首页与详情页留一处竖排文字（如「以舞为栖」），是版面的「气口」

伍 / 05动效规范（可交互演示）Motion

动效只做三类：进入、反馈、点题。克制、短促、有物理感——像纸和印章，不像果冻。

签名动效 · 「盖章」

预约成功、签到成功、审核通过——统一用一个朱砂印章「啪」地盖下来：放大落回 + 轻微斜角 + 一次微震。这是全 App 的记忆点。

底部抽屉（会员码 / 取消确认 / 筛选）

底部操作一律用「纸片上滑」：背景暗下去、纸片带顶部拖拽条上滑到位。不用大面积毛玻璃——模糊背景是当前最滥的手法之一。
