VOLT 舞力场

把会员端做成一间年轻人的舞蹈俱乐部：黑 + 骨白 + 酸性青柠三色到底，海报级大字与「今日登场 SHOWTIME」的课程语言，动效全是「能量」——心电图、均衡器、LOCKED 拳入。全程零渐变、零毛玻璃、零彩虹标签；每天最多 4 节课，所以每节课都是一张大海报，一屏一课，越少越贵。

01设计理念Concept
A

课程即「登场」

借演出的场次制讲约课：课程像每天公演的新场次——名额是座位，预约是「锁定」，开课前倒计时像「即将开演」。稀缺感本身就是年轻人的语言——手慢无。

三色到底

能量可感知

把「上课」翻译成身体反馈：心电图下拉刷新、会员码底部均衡器、LOCKED 拳入 + 屏幕轻震。动效都有物理感，像音乐在心里过拍。

02焦点原则：一屏一大Focus Rule
≤4 / DAY

门店每天课程不超过 4 节——这是优势不是局限。预约页放弃小列表，改用「海报级大卡」：每张卡约占屏高 1/4～1/3，一屏只重点讲一节课。4 张大卡铺出从容的节奏，比 8 张小卡显得课程更值钱、门店更有人气；库存（剩席）用大数字 + 青柠告警，紧张感直接拉满。

05动效规范（可交互演示）Motion

动效五件套全部围绕「能量/节奏」：能互动、有反馈、带情绪。克制处像运动手表，释放处像现场演出。

签名动效 · LOCKED 拳入

预约成功：巨字「LOCKED!」从模糊远处一拳打进 + 票根信息浮现 + 屏幕轻震 + 青柠/黑双色纸屑。抢到课的爽感，一次性给足。
